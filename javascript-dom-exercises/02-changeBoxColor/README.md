# Ejercicio 02 — changeBoxColor

## Contexto

Tienes una caja visual (un cuadrado o rectángulo con un diseño básico) y un botón. El objetivo es modificar el color de la caja mediante JavaScript.

## HTML de partida

```html
<div id="caja-1-2" style="width: 150px; height: 150px; background-color: #ccc; margin-bottom: 10px; border-radius: 8px;"></div>
<button id="btn-1-2">Cambiar color</button>
```

## Objetivo

Al hacer clic en el botón, la caja debe cambiar de color de fondo.

## Requisitos

- Selecciona la caja y el botón desde JavaScript.
- Escucha el evento de clic del botón.
- Cambia el color de fondo de la caja a un color llamativo (por ejemplo, verde, azul o naranja).
- Opcional: cambia de color en cada pulsación o alterna entre varios colores.

# Exercise 02 — changeBoxColor

## Context

You have a visual box (a square or rectangle with a basic design) and a button. The goal is to change the box's color using JavaScript.

## Starting HTML

```html
<div id="caja-1-2" style="width: 150px; height: 150px; background-color: #ccc; margin-bottom: 10px; border-radius: 8px;"></div>
<button id="btn-1-2">Change color</button>
```

## Goal

When the button is clicked, the box must change its background color.

## Requirements

- Select the box and the button from JavaScript.
- Listen for the button's click event.
- Change the box's background color to a striking color (for example, green, blue or orange).
- Optional: change color on every click or cycle through several colors.
