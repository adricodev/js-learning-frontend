# Ejercicio 01 — changeText

## Contexto

Tienes una interfaz sencilla formada por un párrafo de texto y un botón. El objetivo es que el botón modifique el contenido y la apariencia del párrafo mediante JavaScript.

## HTML de partida

```html
<p id="parrafo-1-1">Este es el texto original que vamos a cambiar.</p>
<button id="btn-1-1">Modificar texto</button>
```

## Objetivo

Programar el botón para que, al hacer clic sobre él, el párrafo cambie de texto y de aspecto.

## Requisitos

- Selecciona el párrafo y el botón desde JavaScript.
- Escucha el evento de clic del botón.
- Cambia el texto del párrafo por un mensaje nuevo.
- Modifica al menos un estilo visual del párrafo (por ejemplo, el color del texto y ponerlo en negrita).

# Exercise 01 — changeText

## Context

You have a simple interface made up of a paragraph of text and a button. The goal is for the button to change the paragraph's content and appearance using JavaScript.

## Starting HTML

```html
<p id="parrafo-1-1">This is the original text we are going to change.</p>
<button id="btn-1-1">Change text</button>
```

## Goal

Program the button so that, when clicked, the paragraph changes both its text and its appearance.

## Requirements

- Select the paragraph and the button from JavaScript.
- Listen for the button's click event.
- Change the paragraph text to a new message.
- Modify at least one visual style of the paragraph (for example, the text color and make it bold).
