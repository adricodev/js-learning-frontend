# Ejercicio 03 — toggleClass

## Contexto

Tienes un botón y un elemento (por ejemplo, una tarjeta o una caja). El objetivo es cambiar su apariencia alternando una clase de CSS mediante JavaScript.

## HTML de partida

```html
<div id="caja-1-3" class="card" style="width: 150px; height: 150px; background-color: #e0e0e0; border-radius: 8px; transition: 0.3s;">
  Caja de prueba
</div>
<button id="btn-1-3">Alternar clase</button>
```

## Objetivo

Al hacer clic en el botón, la caja debe alternar (activar/desactivar) una clase CSS que cambie su apariencia.

## Requisitos

- Selecciona la caja y el botón desde JavaScript.
- Escucha el evento de clic del botón.
- Alterna la clase `.activa` en la caja con cada clic.
- Define en CSS la apariencia de `.activa` (por ejemplo, un tamaño mayor, un borde distinto o un fondo especial).

# Exercise 03 — toggleClass

## Context

You have a button and an element (for example, a card or a box). The goal is to change its appearance by toggling a CSS class using JavaScript.

## Starting HTML

```html
<div id="caja-1-3" class="card" style="width: 150px; height: 150px; background-color: #e0e0e0; border-radius: 8px; transition: 0.3s;">
  Test box
</div>
<button id="btn-1-3">Toggle class</button>
```

## Goal

When the button is clicked, the box must toggle (add/remove) a CSS class that changes its appearance.

## Requirements

- Select the box and the button from JavaScript.
- Listen for the button's click event.
- Toggle the `.activa` class on the box with every click.
- Define the appearance of `.activa` in CSS (for example, a larger size, a different border or a special background).
