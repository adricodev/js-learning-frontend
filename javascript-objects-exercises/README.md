# Módulo 1 — Objetos y arrays

[← Volver al índice general](../README.md)

Primer módulo de la colección de ejercicios de JavaScript. Aquí se practica la **manipulación de objetos y arrays** aplicada a casos de uso reales, reforzando la lógica y el uso de los métodos básicos del lenguaje.

## Conceptos clave

- Crear y modificar propiedades de objetos.
- Recorrer y consultar arrays con métodos como `Array.prototype.includes`.
- Añadir elementos con `Array.prototype.push`.
- Uso de condicionales y valores de retorno en funciones.

## Ejercicios

| Nº | Ejercicio | Conceptos |
|----|-----------|-----------|
| 01 | [updateStock](./ejercicio01-updateStock/README.md) | Modificar propiedades de un objeto, condicionales |
| 02 | [hasBook](./ejercicio02-hasBook/README.md) | `Array.prototype.includes`, retorno booleano |
| 03 | [addSong](./ejercicio03-addSong/README.md) | `Array.prototype.push`, crear objetos, retorno |

Cada carpeta contiene el enunciado (`README.md`) y la solución con una prueba mediante `console.log()`.

## Cómo ejecutarlos

Se ejecutan con [Node.js](https://nodejs.org/) desde la carpeta de cada ejercicio:

```bash
node update-stock.js
node librarySection.js
node playlist.js
```

## Recomendaciones de estudio

1. Lee el contexto del ejercicio e intenta resolverlo **antes** de mirar la solución.
2. Prueba con distintos valores de entrada (incluidos casos límite).
3. Compara tu solución con la del archivo `.js` y pregúntate si hay una forma más sencilla.
4. Si un método es nuevo, consulta su documentación en [MDN Web Docs](https://developer.mozilla.org/es/docs/Web/JavaScript).

# Module 1 — Objects and arrays

[← Back to the general index](../README.md)

First module of the JavaScript exercises collection. Here you practice **object and array manipulation** applied to real use cases, reinforcing logic and the use of the language's basic methods.

## Key concepts

- Creating and modifying object properties.
- Looping through and querying arrays with methods such as `Array.prototype.includes`.
- Adding elements with `Array.prototype.push`.
- Using conditionals and return values in functions.

## Exercises

| No. | Exercise | Concepts |
|-----|----------|----------|
| 01 | [updateStock](./ejercicio01-updateStock/README.md) | Modifying object properties, conditionals |
| 02 | [hasBook](./ejercicio02-hasBook/README.md) | `Array.prototype.includes`, boolean return |
| 03 | [addSong](./ejercicio03-addSong/README.md) | `Array.prototype.push`, creating objects, return |

Each folder contains the statement (`README.md`) and the solution with a test using `console.log()`.

## How to run them

They are run with [Node.js](https://nodejs.org/) from each exercise folder:

```bash
node update-stock.js
node librarySection.js
node playlist.js
```

## Study recommendations

1. Read the context of the exercise and try to solve it **before** looking at the solution.
2. Try different input values (including edge cases).
3. Compare your solution with the one in the `.js` file and ask yourself if there is a simpler way.
4. If a method is new to you, check its documentation on [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript).
