# Ejercicios de JavaScript

Repositorio de ejercicios prácticos de JavaScript creado como parte del aprendizaje de **desarrollo frontend**. El objetivo no es solo que el código funcione, sino desarrollar **lógica de programación**, entender el comportamiento del lenguaje y ganar soltura resolviendo problemas cada vez más cercanos a la realidad.

Este README actúa como **índice general** y se irá ampliando a medida que avance en los distintos temarios.

## Sobre estos ejercicios

- Practicar los fundamentos del lenguaje aplicados a casos de uso reales.
- Desarrollar el pensamiento lógico antes de pasar a frameworks.
- Aprender a leer documentación y buscar la herramienta adecuada para cada problema.
- Escribir código claro, con funciones bien definidas y valores de retorno.
- Construir una base sólida sobre la que apoyar el trabajo con datos, estado y componentes.

## ¿Qué encontrarás aquí?

Cada ejercicio vive en su propia carpeta dentro del módulo correspondiente y contiene:

- `README.md` — enunciado con contexto, objeto de ejemplo, objetivo y requisitos.
- Un archivo `.js` con la solución y una prueba mediante `console.log()`.

La estructura se organiza por **módulos temáticos**, que se irán añadiendo con el tiempo.

## Índice de módulos

### Módulo 1 — Objetos y arrays

Manipulación de objetos y arrays (`includes`, `push`) aplicada a casos prácticos.

→ [Ver los ejercicios del módulo](./javascript-objects-exercises/README.md)

### Próximos módulos

Espacio reservado para los siguientes temarios (funciones, estructuras de datos, DOM, eventos, asincronía, etc.).


## Recomendaciones de estudio

1. Lee el contexto del ejercicio e intenta resolverlo **antes** de mirar la solución.
2. Prueba con distintos valores de entrada (incluidos casos límite).
3. Compara tu solución con la del archivo `.js` y pregúntate si hay una forma más sencilla.
4. Si un método es nuevo, consulta su documentación en [MDN Web Docs](https://developer.mozilla.org/es/docs/Web/JavaScript).

# JavaScript Exercises

A collection of practical JavaScript exercises created as part of my **frontend development** learning journey. The goal is not only to make the code work, but to develop **programming logic**, understand how the language behaves and gain confidence solving problems that get closer to real life.

This README works as a **general index** and will grow as I move forward through the different topics.

## About these exercises

- Practice the language fundamentals applied to real use cases.
- Develop logical thinking before moving on to frameworks.
- Learn to read documentation and find the right tool for each problem.
- Write clear code, with well-defined functions and return values.
- Build a solid foundation to support working with data, state and components.

## What will you find here?

Each exercise lives in its own folder inside the corresponding module and contains:

- `README.md` — statement with context, example object, goal and requirements.
- A `.js` file with the solution and a test using `console.log()`.

The structure is organized by **thematic modules**, which will be added over time.

## Modules index

### Module 1 — Objects and arrays

Object and array manipulation (`includes`, `push`) applied to practical cases.

→ [See the module exercises](./javascript-objects-exercises/README.md)

### Upcoming modules

Space reserved for the next topics (functions, data structures, DOM, events, asynchrony, etc.).

## Study recommendations

1. Read the context of the exercise and try to solve it **before** looking at the solution.
2. Try different input values (including edge cases).
3. Compare your solution with the one in the `.js` file and ask yourself if there is a simpler way.
4. If a method is new to you, check its documentation on [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript).
